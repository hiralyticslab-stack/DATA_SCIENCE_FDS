# DATA_SCIENCE_FDS

A collection of data science and exploratory data analysis (EDA) assignments implemented as Jupyter notebooks. Each notebook works with a different dataset and demonstrates common data science tasks such as data loading, preprocessing, descriptive statistics, visualization, and basic predictive analysis.

## Repository Overview

This repository contains several notebook-based assignments covering topics such as:

- Customer purchase prediction
- Hotel review analysis
- Student performance analysis
- Weather forecasting analysis
- House purchase prediction

The projects are designed for learning and practice in Python-based data analysis workflows using libraries such as pandas, NumPy, Matplotlib, and Seaborn.

## Repository Structure

```text
DATA_SCIENCE_FDS/
├── README.md
├── CAR_PUR_FDS.ipynb
├── Hotel_Review.ipynb
├── Student_Performance.ipynb
├── Weather_Forecast.ipynb
├── house_purchase.ipynb
├── carpurchase.csv
├── diabetes.csv
├── hotel_review.csv
├── house_purchase_prediction_500_records.csv
├── student-mat.csv
└── ...
```

## Included Notebooks

- `CAR_PUR_FDS.ipynb`  
  Analysis of a car purchase dataset, including demographic variables such as age, salary, and purchase status.

- `Hotel_Review.ipynb`  
  EDA and review-related analysis using hotel review data.

- `Student_Performance.ipynb`  
  Analysis of academic and demographic variables affecting student performance.

- `Weather_Forecast.ipynb`  
  Weather-related dataset exploration and forecasting-style analysis.

- `house_purchase.ipynb`  
  Housing-related prediction dataset used for feature analysis and modeling tasks.

## Technologies Used

- Python
- Jupyter Notebook
- pandas
- NumPy
- Matplotlib
- Seaborn

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hiralyticslab-stack/DATA_SCIENCE_FDS.git
cd DATA_SCIENCE_FDS
```

### 2. Create a virtual environment (optional but recommended)

```bash
python -m venv venv
source venv/bin/activate   # Linux/macOS
venv\Scripts\activate      # Windows
```

### 3. Install dependencies

```bash
pip install jupyter pandas numpy matplotlib seaborn
```

### 4. Run Jupyter Notebook

```bash
jupyter notebook
```

Then open any notebook in the repository and run the cells in order.

## Data Files

The repository includes several CSV datasets used by the notebooks:

- `carpurchase.csv`
- `diabetes.csv`
- `hotel_review.csv`
- `house_purchase_prediction_500_records.csv`
- `student-mat.csv`

These files are expected to be located in the same directory as the notebook when running locally.

## Notes

- Some notebooks were originally designed to run in Google Colab.
- If you are working locally, ensure that the dataset paths match your working directory.
- The project is educational and structured around practical data analysis exercises.
